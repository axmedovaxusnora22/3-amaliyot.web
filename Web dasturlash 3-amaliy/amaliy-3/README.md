3-amaliy ish — JavaScript asoslari

Talaba: Ahmedova Xusnora Oybek qizi

Guruh: 941-24

Variant: 1

Amaliy ish mavzusi

JavaScript asoslari: sonlar, satrlar va massivlar bilan ishlash.

Bajarilgan masalalar

1. `darajaHisobla(a, n)` — sonni darajaga ko‘tarish.
2. `undoshlarSoni(s)` — so‘zdagi undosh harflarni sanash.
3. `ortachaQiymat(arr)` — massivdagi sonlarning o‘rtacha qiymatini topish.
4. `ikkilikdanOnlikka(s)` — ikkilik sonni o‘nlik sanoq sistemasiga o‘tkazish.
5. `kesishma(a, b)` — ikkita massivdagi umumiy elementlarni topish.

Ishga tushirish tartibi

1. `index.html` faylini brauzerda ochish.
2. Klaviaturadan F12 tugmasini bosish.
3. Console bo‘limida natijalarni ko‘rish.

Dasturlash tili: JavaScript
